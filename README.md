# 🦷 SmileCare Dental Clinic

A fully functional, animated single-page website for a modern dental clinic.

![Status](https://img.shields.io/badge/status-live-brightgreen)

## ✨ Features

- **Animated hero** with floating graphics, blobs and scroll reveals
- **Sticky navigation** with scrollspy (active section highlighting) + animated mobile menu
- **Service filtering** — preventive / cosmetic / restorative categories
- **Animated counters** (patients, years, specialists, satisfaction)
- **Testimonials slider** — auto-rotating with dots & arrows
- **Appointment booking form** — client-side validation + saves to `localStorage`
- **FAQ accordion** with smooth animations
- Fully responsive layout

## 🛠 Tech Stack

- HTML5
- CSS3 (custom properties, keyframes, responsive design)
- Vanilla JavaScript (ES6, IntersectionObserver)

## 🚀 Getting Started

Open `index.html` in a browser, or serve it locally:

```bash
# Python
python -m http.server 8080

# Node
npx serve .
```

Then visit `http://localhost:8080`.
